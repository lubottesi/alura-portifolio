# Portfolio Template

A two-page portfolio template for a fictional front-end developer: a home page with an intro and social links, and an "about me" page.

Alura's first HTML/CSS project.

**Live:** https://alura-portifolio-flax-gamma.vercel.app

## Stack

- HTML5
- CSS3

## Running locally

No build step - open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then go to http://localhost:8000.

## Structure

```
index.html
about.html
styles/style.css
assets/
```
